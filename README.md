# Geo360
GeoMet360 is an AI-powered geometallurgical intelligence platform that predicts ore performance before processing. Using mineralogical, ore and historical plant data, it forecasts recovery, throughput, energy and water impacts, helping mining teams make smarter, more sustainable decisions.
